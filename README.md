# Weekend Theory

A premium, mobile-first landing page for a curated group-travel brand operating from Bengaluru.

## Current features
- Editorial-style homepage and responsive layout
- Trip cards for nature escapes, movie-inspired trails, and social group trips
- Client-side experience filters
- Trip enquiry modal with validation
- WhatsApp handoff for enquiries
- Accessible labels, keyboard-close modal, reduced dependency footprint

## Important launch checklist
The trip concepts, dates, and prices shown on the site are **demonstration content**, not live offers. Replace them with verified itineraries, actual prices, confirmed departure dates, pickup details, inclusions/exclusions, minimum group size, cancellation/refund terms, and customer-support contact details before advertising.

The current form is an enquiry flow only. It **does not collect money, reserve seats, or confirm bookings**. Before accepting advances, implement a secure backend and payment gateway integration (e.g. Razorpay), server-side payment signature/webhook verification, seat inventory locking, booking records, refund handling, and privacy/terms pages. Never put payment secrets in frontend code.

## Publish with GitHub Pages
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then Save.
4. Wait for the deployment URL shown in Settings → Pages.

The site uses externally hosted Google Fonts and Unsplash images, so those assets require an internet connection.
