# OPEX user guide

## Connect and sign in
Open OPEX in desktop Chrome/Edge, choose the approved shared workspace folder, then sign in with your employee ID, password and workspace passphrase. If the folder permission is lost, return to the login page and reconnect it.

## Submit a form
Open **Submit**, select an assigned form, complete required fields and submit. The record is placed in a local outbox and the app attempts to append it to the shared workspace. Confirm that it is visible in the supervisor queue before assuming another user can see it.

## Respond to a pend
Open **My items**, read the supervisor's reason and due date, update the requested fields and resubmit. The item returns to the review queue as a new version.

## Dashboards
Open **Dashboards** and select an authorized dashboard. Use refresh after new submissions have synced. Export currently produces CSV, not XLSX.

## Important
The current offline queue is browser-profile specific. Keep the app open while syncing and report any failed sync or integrity warning to the administrator. Never share your password or workspace passphrase. Use synthetic data only during the prototype pilot.
